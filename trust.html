Trust is built on evidence.

A clear explanation of what we can demonstrate, what requires further testing, and what has not been independently audited.

Verification status: This page does not claim an independent security audit, SOC 2 certification, or endorsement by any testing provider. External website configuration scans are not comprehensive product security audits.

Understand where your information lives

Roofmere offers local-browser and self-hosted configurations. Local-browser storage uses IndexedDB. Self-hosted configurations involve services that you configure and operate. The precise behavior of each edition and feature should be checked against its current release and privacy documentation before entering sensitive information.

Independent website checks

These third-party services let you inspect public-facing website configuration. Results are generated by the providers, may change over time, and do not validate Roofmere application logic or data isolation.

  • Mozilla Observatory — browser-facing security configuration
  • SecurityHeaders — HTTP response header configuration
  • Qualys SSL Labs — HTTPS/TLS configuration

We will publish dated results only after they have been run and reviewed. No score or passing grade is claimed here.

Data reliability

Backup and restore, import/export, database upgrades, and account access isolation require release-specific testing. A test is not considered verified merely because a feature exists. Until a dated, reproducible report is linked here, no comprehensive test certification is claimed.

Questions or concerns?

Use the contact and support channels on the Roofmere homepage. Please do not send passwords, API keys, full account numbers, or sensitive financial documents in a support request.
