# Roofmere Website

Public, static marketing landing page for Roofmere. Hosted using GitHub Pages once enabled.

## Publish
GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Expected URL after Pages publishes: https://lilycao2026.github.io/roofmere-website/

## Assets
- `assets/app-dashboard.jpg`: the real app showing the fictional sample family (Local Mode, `?sample`), header and setup card hidden.
- `assets/roofmere-architecture.svg` (wide screens) and `assets/roofmere-architecture-mobile.svg` (phones, chosen by `<picture>` below 700 px). Keep both in step when the architecture changes.
